Spec/Convention Name: CPS Key Convention
Version: 1.0.1
Last Updated: 2026-01-07

0. 목적
routeKey, sequenceKey, ScriptableObject 에셋 이름을 일관된 규칙으로 관리한다.
로그/트레이스에서 한 줄만 봐도 어느 스토리/이벤트/튜토리얼인지 바로 알 수 있게 한다.
기획/연출/개발이 같은 키를 같이 쓸 수 있도록 한다.


1. 런타임 키 포맷

1-1. 기본 패턴
런타임에서 사용하는 모든 키(routeKey, startKey, sequenceKey)는 다음 형식을 따른다.

[scope][NN].[track].[MM]

(1) scope[NN] : 스토리/이벤트/튜토리얼 등 그룹/에피소드 단위
-예: story00, story01, event01, tutorial00, system00
(2) track : 트랙/용도
예: dialogue, cutscene, battle, tutorial
(3) MM : 해당 트랙 안에서의 시퀀스 번호 (01부터 시작)

규칙
(1) 전부 소문자 + 숫자 + 점('.') 만 사용
(2) 번호(NN, MM)는 항상 2자리로 표기 (00, 01, 02 …)
(3) 키는 순수 라벨/주소로 쓰고, 숫자를 파싱해서 인덱스로 쓰지 않는다.

1-2. 예시
story00.dialogue.01  // 스토리 0, 첫 번째 대사 시퀀스
story00.dialogue.02  // 스토리 0, 두 번째 대사 시퀀스
story01.dialogue.01  // 스토리 1, 첫 번째 대사 시퀀스

event01.dialogue.01  // 이벤트 1, 첫 번째 대사 시퀀스
event02.dialogue.01  // 이벤트 2, 첫 번째 대사 시퀀스

tutorial00.dialogue.01  // 튜토리얼 0, 첫 번째 대사 시퀀스

system00.dialogue.01    // 시스템 공용 연출 (예: 설정 화면 안내)


2. Route / Sequence 키 매핑 규칙

2-1. 기본 원칙
가능한 한 다음을 동일한 문자열로 맞춘다:

[1]RouteMapping.routeKey
[2]RouteMapping.startKey
[3]SequenceSpecSO.sequenceKey

routeKey     = "story00.dialogue.01"
startKey     = "story00.dialogue.01"
sequenceKey  = "story00.dialogue.01"

2-2. RouteCatalog 구성 예시
[Serializable]
public sealed class RouteMapping
{
    public string routeKey;                  // 예: "story00.dialogue.01"
    public SequenceCatalogSO sequenceCatalog; 
    public string startKey;                  // 예: "story00.dialogue.01"
}

예시 테이블:
routeKey                 sequenceCatalog         startKey
--------------------------------------------------------------
story00.dialogue.01      SequenceCatalog_Story   story00.dialogue.01
story01.dialogue.01      SequenceCatalog_Story   story01.dialogue.01
event01.dialogue.01      SequenceCatalog_Event   event01.dialogue.01
tutorial00.dialogue.01   SequenceCatalog_Tutorial tutorial00.dialogue.01


3. ScriptableObject 에셋 이름 규칙

3-1. SequenceSpecSO
Seq_[Scope][NN]_[Track]_[MM]

예:
Seq_Story00_Dialogue_01    // sequenceKey = "story00.dialogue.01"
Seq_Story00_Dialogue_02    // sequenceKey = "story00.dialogue.02"
Seq_Event01_Dialogue_01    // sequenceKey = "event01.dialogue.01"
Seq_Tutorial00_Dialogue_01 // sequenceKey = "tutorial00.dialogue.01"

3-2. SequenceCatalogSO
도메인/범위 별로 나눈다:

SequenceCatalog_Story00
SequenceCatalog_Event00
SequenceCatalog_Tutorial00
SequenceCatalog_System00


3-3. RouteCatalogSO
게임 전체 / 컨텍스트별로:

RouteCatalog_Main
RouteCatalog_Debug


4. 예외

4-1. 팔레트/샘플 시퀀스
팔레트/샘플 시퀀스는 Editor/Importer에서만 사용하기 위해 제작된 SequenceSpecSO를 의미한다.

팔레트/샘플 시퀀스는 Route에서 직접 시작되지 않으며,
“좋았던 Step들을 물감 튜브처럼” 모아두고,
별도 Importer를 통해 타겟 Sequence로 복사하여 사용하는 용도이다.

따라서 팔레트/샘플 시퀀스는 다음 예외 규칙을 따른다.
(1) sequenceKey는 필수로 작성하지 않아도 된다.
(2) assetName에는 가능하면 `_Palette`를 포함할 것을 권장한다.
    예:
    sequenceKey = ""
    assetName   = "Seq_Palette_Default"
(3) 팔레트/샘플 시퀀스는 Palette 전용 SequenceCatalogSO에 모아둔다.
(3-1) Palette 전용 SequenceCatalogSO의 assetName에도 가능하면 `_Palette`를 포함할 것을 권장한다.
(3-2) Palette 전용 SequenceCatalogSO의 CatalogId에도 가능하면 팔레트임을 표시할 것을 권장한다.
